# 사이트 설계도(PRD) — 원데이 클래스 강의 예약 사이트

작성일: 2026-10-17 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
주중·주말에 열리는 원데이 클래스를 소개하고, 손님이 사이트에서 바로 예약 신청을 남기는 곳.
(수업 종류: 미정)

## 2. 손님
- 누가:
  - 주중에도 배우려는 관계자
  - 취미를 찾는 직장인
- 어디서 알고 오나:
  - 네이버 검색·블로그
  - 유튜브 (나중에 채널을 열어 안내 글을 올릴 예정)

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 가격·재료비 — 수강료가 얼마이고, 재료비가 따로 드는지
2. 수업 날짜·시간 — 주중·주말 언제 열리고 몇 시간 걸리는지
3. 초보 가능 여부 — 처음이어도 따라갈 수 있는지

## 4. 믿게 할 증거 (실제로 있는 것만)
- 강사 경력·자격증: 있음 (구체적인 내용은 미정 — 사용자가 채운다. 지어내지 않는다)
- 수업·작품 사진: 아직 없음 (자리만)
- 후기: (실제 후기가 생기면 넣는다. 지금은 자리만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 예약 신청
- 누르면: 예약 신청 폼 → 저장 → 관리자 페이지(/admin)에서 확인
- **지금 상태 (2026-10-17): "예약 준비중"** — 버튼과 폼이 잠겨 있어 실제 예약은 받지 않는다.
  수업 정보가 모두 정해지면 `config.js`에서 `bookingOpen: true`로 바꾸고, 예약 저장(Supabase + /api/reserve)을 연결해 `bookingEndpoint`에 적는다.

## 6. 페이지 구성 (위에서 아래로, 한 장짜리 페이지)
1. 첫 화면 — 한 문장 + [예약 신청] 버튼
2. 수업 소개 — 무엇을 만드는지 / 초보도 가능하다는 안내 (내용 미정)
3. 가격·재료비와 수업 일정 (주중·주말) — 미정이면 "준비 중"
4. 강사 소개 — 경력·자격증 (사용자가 준 내용만)
5. 후기 자리 (비워 둠)
6. 예약 신청 폼

## 7. 예약 신청 폼에서 받을 것
- 이름, 연락처
- 희망 수업 날짜 (주중/주말)
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 수업 종류: (미정)
- 가격: (미정)
- 시간: (미정)
- 위치: (미정)
- 연락 방법: (미정)

## 9. 이번에 넣지 않을 것
- 결제 (다음에)
- 회원가입·로그인 (다음에)
- 사진 올리기 기능, 알림 메일 (다음에)
- 유튜브 영상 넣기 (채널을 연 뒤에)

## 10. 첫 화면 한 문장 후보
1. 처음이어도 괜찮아요, 하루 만에 완성하는 원데이 클래스
2. 바쁜 주중에도, 여유로운 주말에도 — 나를 위한 하루 수업
3. 경력 있는 강사와 함께하는 소규모 원데이 클래스

## 11. 다음에 할 것
- 수업 종류·가격·일정·위치·연락 방법 정하기 → `config.js`에 적기
- 예약 열기: 예약 저장(Supabase + /admin) 연결 후 `config.js`의 `bookingOpen`을 `true`로
- 강사 경력·자격증 문구 정리해서 넣기
- 수업·작품 사진 찍어 넣기
- 첫 수강생 후기 받으면 후기 자리 채우기
- 유튜브 채널 열면 사이트에 링크 연결
- 네이버 검색에 잘 나오도록 네이버 서치어드바이저 등록

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 고급스러운 · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel
  - 사이트 주소: https://oneday-class-site.vercel.app
  - 저장소: https://github.com/idbargab-stack/oneday-class-site (main에 Push하면 자동 배포)

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 예약 신청 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
